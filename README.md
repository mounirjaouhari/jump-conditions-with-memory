# Jump conditions with memory

Reproducible computational pipeline for the article

> **Jump conditions with memory for the dynamic homogenization of a thin row
> of elastic inclusions in a viscoelastic matrix**
> Mounir Jaouhari, Anas Rachid, Amine Sbitti and Rachid Belemou.
> *Mathematics and Mechanics of Solids* (manuscript MMS-26-0236, revised
> version under review).

Hereditary jump conditions for a thin periodic row of elastic inclusions in a
Kelvin–Voigt viscoelastic matrix: memory kernels obtained from cell problems,
a Herglotz–Stieltjes passivity proof, and finite-element validation against
the actual scattering problem. **Every figure and every number quoted in the
article is regenerated by this repository**, and every run is traced back to
the exact code, configuration and environment that produced it.

## Scientific overview

**Setting.** Anti-plane shear waves cross a thin periodic row (period $h$,
thickness $e$, filling fraction $\varphi$) of elastic inclusions embedded in
a Kelvin–Voigt viscoelastic matrix, in the long-wavelength regime
$\eta = kh \ll 1$. Following the matched-asymptotic route of Marigo, Maurel
and co-workers, the row is replaced by an **effective interface** of
thickness $a$ carrying jump conditions. The distinctive feature here is the
viscous degeneracy — the matrix is dissipative, the inclusions are not —
which, after homogenization, makes the interface **hereditary**.

**The model** (*formal derivation*, matched asymptotics in the Laplace
variable $p$). In the Laplace domain the jump conditions are algebraic,

```math
[\![\,\widehat U\,]\!]_a = h\,B(p,a)\,\langle \partial_{X_1}\widehat U\rangle_a
```
```math
[\![\,\widehat\Sigma_1\,]\!]_a = h\,S(a)\,\langle \widehat{\mathrm{div}\,\Sigma}\rangle_a
 - h\,C(p,a)\,\langle \partial_{X_2}\widehat\Sigma_2\rangle_a
```

and back in time they combine instantaneous averages with convolutions
against two causal memory kernels ($B^v = C^v = 0$ for $\varphi < 1$):

```math
[\![\,U\,]\!]_a = h\,B^{e}\langle \partial_{x_1}U\rangle_a
 + h\int_0^t K_B(t-s)\,\langle \partial_{x_1}\dot U(s)\rangle_a\,ds
```
```math
[\![\,\Sigma_1\,]\!]_a = h\,S\,\langle \mathrm{div}\,\Sigma\rangle_a
 - h\,C^{e}\langle \partial_{x_2}\Sigma_2\rangle_a
 - h\int_0^t K_C(t-s)\,\langle \partial_{x_2}\dot\Sigma_2(s)\rangle_a\,ds
```

**The pivot** (*proved*): the cell solution depends on $p$ only through the
complex modulus contrast $r(p) = M_i(p)/M_m(p) = \mu_i/(\mu_m + p\beta_m)$,
so the interface coefficients are functions of one variable —
$B(p,a) = a/h + G(r(p))$, and similarly for $C$.

**Two memory mechanisms** (*proved*): the normal kernel $K_B$ is a bypass
effect — the flux can go around the inclusions through the viscous matrix —
and vanishes identically for a full layer ($\varphi = 1$); the transverse
kernel $K_C$ comes from the volumetric contrast, survives at $\varphi = 1$
in closed form, $K_C(t) = -(e/h)(\mu_i/\mu_m)\,e^{-\lambda t}$ with
$\lambda = \mu_m/\beta_m$, and acts **only at oblique incidence**.

**Passivity** (*proved, on the whole complex half-plane*): an exact Herglotz
identity, $\mathrm{Im}\, B(r) = -\mathrm{Im}\, r
\int_{\Omega_i}|\nabla V^{(1)}|^2$ (and $+$ for $C$), shows that $-B$ and
$C$ are Herglotz functions of the contrast; by the Nevanlinna representation
their Stieltjes measures are **positive**, whence
$\mathrm{Re}\,[p\widehat K_B] \ge 0$ and
$\mathrm{Re}\,[p\widehat K_C] \le 0$ for all
$\mathrm{Re}\,(p) > 0$, and the complete monotonicity of both exact
kernels (Bernstein) as a corollary.

**Every claim has a numerical witness in this repository:**

| Statement | Status | Witness |
|---|---|---|
| Interface model (jump conditions with memory) | formal derivation | validated below |
| Reduction to the contrast $r(p)$ | proved | `bloc1` energy identities ≈ 1e-10, complex $r$ included |
| Two mechanisms ($K_B$ bypass, $K_C$ contrast) | proved | `bloc2` kernels; full layer vs closed form ≈ 3e-11 (`bloc1`) |
| Herglotz identity | proved | `bloc9`: residual ≈ 1.1e-10 over both half-planes |
| Stieltjes measure ≥ 0 (passivity on the half-plane) | proved | `bloc9`: sampled density $\mu' \ge 0$; reconstruction ≈ 4 % |
| $O((kh)^2)$ convergence to the actual problem | numerical observation | `bloc3` (normal), `bloc6` (oblique, Bloch reference) |
| $C$ indispensable at oblique incidence | numerical observation | `bloc6`: omitting $C$ → error does not converge |
| Superconvergence of $a = e$ | numerical observation | `bloc4`, `bloc8` (scattering + field norms) |
| Accuracy floor of the reference solver | **measured** | `bloc10`: 2.5e-4, mesh order 1.93 |
| Elastic limit = published values of the elastic case | external check | `tests/test_marigo.py` (14 tests) |

Open questions (stated as such in the article): passivity of the *coupled*
interface system in the power sense, exact energy balance of the
internal-variable model, a time-domain convergence theorem.

## Requirements

- Python ≥ 3.10 (developed and tested with CPython 3.13);
- the packages of [`requirements.txt`](requirements.txt) (NumPy, SciPy,
  Matplotlib, pandas, PyYAML, pytest);
- no compiled extension, no GPU: everything runs on a laptop.


## Quick start

```bash
python run.py test      # 101 automated tests            (~6 min)
python run.py all       # all data + all figures          (~45 min)
python run.py verify    # audit: is every output traceable?
```

`run.py` is the **single entry point** of the project. `all` executes the
eleven computation blocks in order, exports the values quoted by the paper,
and finishes with the traceability audit.

## Reproducing the paper

Each figure of the article is produced by exactly one block, and can be
regenerated alone (`python run.py bloc4`, etc.):

| Block | Purpose | Figures | Data |
|---|---|---|---|
| `bloc0` | Geometry and schematic illustrations | fig01–fig04 | — |
| `bloc1` | Cell coefficients B(p), C(p), S(a) + solver checks | fig05, fig06 | 1 CSV, 22 values |
| `bloc2` | Memory kernels K_B(t), K_C(t) (Laplace inversion) | fig07 | 3 CSV, 13 values |
| `bloc3` | Harmonic scattering R, T at normal incidence | fig09 | 1 CSV, 9 values |
| `bloc4` | Choice of the interface thickness a; superconvergence | fig08, fig11 | 3 CSV, 3 values |
| `bloc5` | Transient propagation (exact transfer-function route) | fig12, fig13 | 3 CSV, 11 values |
| `bloc6` | Oblique incidence: validation of the coefficient C | fig15, fig16 | 2 CSV, 9 values |
| `bloc7` | In which spectral regime does memory matter? | fig17 | 1 CSV, 8 values |
| `bloc8` | Field maps: near field and the role of C | fig18–fig20 | 5 CSV, 6 values |
| `bloc9` | Passivity on the half-plane: Herglotz identity, Stieltjes measure | fig14 | 2 CSV, 5 values |
| `bloc10` | Accuracy of the *reference* solver: measured floor (S8) | fig21 | 4 CSV, 6 values |

(The file numbering has one gap: an early `fig10` was merged into `fig09`.)

Numbers quoted in the article are never typed by hand: each block records its
citable values, and `python run.py export` turns them into LaTeX macros
(`\FMBe → 0.584`, …) that the manuscript inputs. A value printed in the
paper cannot diverge from the code that computed it.

## Provenance: how outputs are traced

Four locks, detailed in [`docs/REPRODUCIBILITY.md`](docs/REPRODUCIBILITY.md):

1. **One configuration file.** Every physical and numerical parameter lives in
   [`config/default.yaml`](config/default.yaml); its SHA-256 is recorded in
   every run manifest. No number is hard-coded in a script.
2. **One manifest per run.** `results/<config>/<block>/manifest.json` records
   the git commit (and whether the tree was clean), the configuration hash,
   the library versions, every exported value, and the SHA-256 of every
   output file.
3. **Data, not only images.** Every plotted curve is also written to CSV next
   to its manifest — a referee can recompute an error without rerunning
   anything.
4. **An audit command.** `python run.py verify` re-hashes everything and
   flags orphan figures, retouched figures and non-replayable runs.

## Tests

`python run.py test` runs 101 tests: solver invariants (energy conservation,
zero-contrast invisibility, closed-form full layer), external validation
against the published values of the elastic case, golden-value
non-regression, and one gate per numerical correction that was expensive to
find — so no known defect can silently return.
